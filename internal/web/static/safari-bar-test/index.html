Safari bar test

Each link reloads the page with one way of keeping Safari's bar the same color as the top bar.

    1. Open a version from the list above. Safari's bar should be red.
    2. Press Play: the top bar turns dark gray. Does Safari's bar turn dark?
    3. Press Pause: the top bar turns red. Does Safari's bar turn red again?
    4. Repeat once more, then try the next version.
